# 📱 Мобильное приложение "Теплый пол Стаса" (Android)

Современное нативное Android-приложение для управления двухзонным теплым полом и комнатным отоплением по протоколу MQTT (WQTT / локальный брокер).

---

## 🚀 Как открыть и собрать APK в Android Studio:

1. Запустите **Android Studio**.
2. Выберите **Open** (или `File -> Open...`).
3. Укажите папку:
   `D:\Project\ESP\WarmFloor_Stas\android_app`
4. Дождитесь автоматической синхронизации Gradle (Gradle Sync).
5. Чтобы получить готовый установочный файл APK:
   - В верхнем меню выберите **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
   - По завершении сборки в правом нижнем углу появится уведомление `APK(s) generated successfully` со ссылкой **locate** на готовый `.apk` файл (`app-debug.apk`).
   - Скопируйте этот APK на телефон и установите.

---

## ⚙️ Первоначальная настройка в приложении:

При первом запуске на смартфоне:
1. Нажмите иконку **шестеренки ⚙️** в правом верхнем углу.
2. Введите параметры WQTT брокера:
   - **Адрес брокера:** `wqtt.ru` (или IP локального сервера)
   - **Порт:** `1883`
   - **Логин:** Ваш логин на WQTT
   - **Пароль:** Ваш пароль на WQTT
   - **Префикс:** `warmfloor`
3. Нажмите **"СОХРАНИТЬ И ПОДКЛЮЧИТЬСЯ"**.
4. Настройки сохраняются в памяти телефона (`SharedPreferences`) — вводить их каждый раз не нужно.

---

## 🎯 Возможности приложения:

- **Статус соединения:** Индикатор в реальном времени отображает подключение к брокеру и онлайн-статус самого контроллера ESP32 (`warmfloor/status`).
- **Главный выключатель:** Одной кнопкой включает или выключает все отопление помещения (`warmfloor/power`).
- **Регулировка уставок:** Кнопки `+` и `-` с шагом 0.5°C для общей уставки теплого пола (`warmfloor/floor/set_target`) и температуры воздуха (`warmfloor/air/set_target`).
- **Карточки зон пола (Зона 1 и Зона 2):** Текущая температура пола, бейджи состояния реле SSR (*Нагрев*, *Останов воздухом*, *Пол прогрет*, *Выключен*).
- **Карточка воздуха:** Текущая температура комнатного воздуха и статус потребности в тепле.
